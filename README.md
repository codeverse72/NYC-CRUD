# 📂 NYC CRUD - File Management System

A modern File Management System built with **Python** and **Streamlit**.

The application provides CRUD (Create, Read, Update, Delete) operations for files and folders through an interactive web interface.

---

## Features

- 📁 Create files
- 📂 Create folders
- 📄 Read file contents
- ✏️ Rename files
- 📝 Append content
- 🔄 Overwrite content
- ❌ Delete files
- 📋 List directory contents
- 🎨 Modern Streamlit UI

---

## Technologies Used

- Python
- Streamlit
- pathlib
- os
