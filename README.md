# 📂 NYC CRUD - File Management System

A modern **File Management System** built using **Python** and **Streamlit** that allows users to perform CRUD (Create, Read, Update, Delete) operations on files and folders through a simple and interactive web interface.

---

## 🚀 Features

- 📄 Create new files
- 📁 Create new folders
- 📖 Read file contents
- ✏️ Rename files and folders
- ➕ Append content to existing files
- 🔄 Overwrite file contents
- ❌ Delete files and folders
- 📋 Browse directory contents
- 🛡️ Exception handling for safer file operations
- 🎨 Clean and user-friendly Streamlit interface

---

## 🛠️ Technologies Used

- Python 3
- Streamlit

- File Handling

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/codeverse72/NYC-CRUD.git
```

### 2. Navigate to the project

```bash
cd NYC-CRUD
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run fileManager.py
```

The application will open in your browser.
